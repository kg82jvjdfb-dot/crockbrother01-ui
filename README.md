# VadyaWay Рецепты

Русскоязычный прототип для iOS и Android на Expo и React Native. В каталоге три демонстрационных рецепта. Граммовки, время и формулировки нужно сверить с автором перед публикацией. Каталог лежит в `recipes.js`. Избранное хранится на устройстве, аккаунт не требуется.

## Запуск

Установите Node.js 22 LTS и Expo Go, совместимый с SDK 54, на телефон. В каталоге проекта выполните:

```sh
npm install
npm start
```

Подключите телефон и компьютер к одной сети Wi-Fi. На iPhone откройте QR-код камерой, на Android используйте сканер в Expo Go. Для эмулятора с совместимым Expo Go используйте `npm run ios` или `npm run android`.

Совместимые версии Expo Go: https://expo.dev/go

## Проверка на телефоне

- Поиск по названию и ингредиентам, фильтры по категориям.
- Открытие рецепта, отметки шагов, пересчёт числовых количеств на 1–12 порций.
- Добавление и удаление избранного, сохранение после перезапуска.
- Возврат из рецепта кнопкой интерфейса и системной кнопкой Android.

Архив содержит исходный код проекта.
